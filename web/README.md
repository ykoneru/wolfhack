# FlowMap map

From `web/`, run `npm install` and `npm run dev`. The page loads Wake County tracts, places, and weekday activity from `public/`.

Start the API from the repo root so Hear why, speech, and the saved series work:

```bash
.venv/bin/python api/server.py
```

`npm test` checks the activity bands and that a closing place does not win the quietest hour when the visit will not fit.
